# Layer 2 — idea-conditioned end-to-end revision

Input is a plausible scientific idea with a genuine, validated improvement
opportunity embedded inside normal task content. The evaluated agent starts at
the beginning of its native end-to-end workflow and must generate the evidence
needed to discover the problem.

The public environment exposes a fixed-budget generic research interface, not
a list of case-specific diagnostic actions or allowed revision directions.

Layer 2 uses the same repair contracts and evaluator as Layer 1. It differs only
in start state, horizon, and terminal artifact scope.
